# Travel Assistant Skill 

智能旅行规划助手，整合小红书攻略搜索、飞猪酒店预订、高德地图路径规划，为用户提供一站式旅行解决方案。

## 核心特性

- **模型解析** — 所有非结构化数据（小红书笔记、飞猪输出）由 openclaw 调用模型分析，不使用正则
- **实时数据** — 每次搜索都是新数据，不使用缓存或内置数据库
- **可复用模板** — 独立 HTML 模板文件，Python 只做数据填充
- **真实交通** — 高德 transit API 完整换乘方案
- **Python 实现** — 主流程用 Python 编写

## 使用方法

```bash
# 添加执行权限（首次）
chmod +x travel

# 基本用法
travel --city 武汉 --start_time 2026-04-16_12:00 --end_time 2026-04-18_19:00 --cost 500

# 参数说明
--city        旅行城市（必需）
--start_time  开始时间，格式 YYYY-MM-DD_HH:MM（必需）
--end_time    结束时间，格式 YYYY-MM-DD_HH:MM（必需）
--cost        总预算，单位元（必需）
```

## 依赖技能

1. **小红书** (xiaohongshu) — 搜索旅游攻略
2. **高德地图** (amap) — POI搜索、路径规划、地图可视化
3. **飞猪** (flyai) — 酒店搜索和预订

## 输出

生成的 HTML 报告位于 `outs/` 目录，包含：
- 交互式地图（AMap JSAPI 2.0）
- 每日行程时间轴
- 酒店推荐与预订链接
- 详细交通换乘方案
- 预算分配
- 美食推荐
- 避雷建议
